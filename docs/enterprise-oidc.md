# 飞书新账号加入共享空间

OIDC 登录保留原来的邮箱匹配逻辑：邮箱匹配已有账号时使用该账号；匹配不到时创建独立的新用户。不会根据飞书 subject、姓名或 AgentOS 身份把不同邮箱的账号合并或绑定。

云端服务端配置：

```yaml
oidc_auth:
  new_user_tenant_id: 10000
```

该配置只影响新建的 OIDC 用户：直接加入指定的已有空间，角色为 Contributor，不创建个人空间，不获得空间 Owner 权限。已有账号的资料、密码、空间成员关系、登录空间选择和 API Key 均不改变。设为 0 时沿用原有自动注册策略。密码注册、邀请注册和 AgentOS 外部员工开户路径保持原样。

目标空间不存在或停用时拒绝创建用户，不会回退创建另一个空间。目标空间编号由服务端决定，浏览器注册请求不能自行指定。

数据库迁移 96 / SQLite 18 移除上一版新增的 subject 绑定表，彻底恢复邮箱匹配；此前的 95 / SQLite 17 迁移保留在历史中以支持已有部署平滑升级。新飞书账号与旧员工账号分别保留用户 ID 和私有数据，不因同处空间 10000 而继承另一账号的私有知识库。
